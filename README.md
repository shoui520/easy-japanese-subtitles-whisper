# Easy Japanese Subtitles

Drop videos or folders to generate Japanese .srt subtitle files on your PC.

## Download

Download the Windows ZIP from [Releases](https://github.com/shoui520/easy-japanese-subtitles-whisper/releases), extract it, and open **Easy Japanese Subtitles.exe**. 

## Requirements

- Windows 10 22H2 or Windows 11 (x64)
- Recommended: A CUDA comaptible NVIDIA GPU with an up-to-date driver for CUDA acceleration. CPU processing is supported but slower; setup also offers Intel XPU and AMD ROCm for supported GPUs.
