# Easy Japanese Subtitles

Drop videos or folders to generate Japanese subtitles on your PC.

## Download

Download the Windows ZIP from [Releases](https://github.com/shoui520/easy-japanese-subtitles-whisper/releases), extract it, and open **Easy Japanese Subtitles.exe**. First-run setup downloads the required components automatically.

## Requirements

- Windows 10 22H2 or Windows 11, x64 (Intel or AMD processor). Windows 10 compatibility is expected but not yet tested.
- Microsoft Edge WebView2 Runtime.
- Internet for initial setup and model downloads; downloaded models work offline.
- A writable app folder and several gigabytes of free disk space for components and models.
- Optional: a compatible NVIDIA GPU with an up-to-date driver for CUDA acceleration. CPU processing is supported but slower; Intel/AMD GPU setup is not yet automatic.
